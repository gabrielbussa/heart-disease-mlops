# Video demonstration plan (record only after real execution)

Target duration: 4–6 minutes.

1. Show the repository and README.
2. Show dataset source and the actual EDA summary and plots.
3. Run training and show actual cross-validation/test metrics.
4. Open MLflow and show both model runs with parameters, metrics, and artifacts.
5. Run Pytest and show the real pass/fail output.
6. Show the GitHub Actions run and its logs.
7. Build the Docker image, start the container, and call `/health` and `/predict`.
8. Show deployment resources and the real reachable endpoint or local access instructions.
9. Show monitoring/log output.
10. Close with limitations and the fact that the model is educational only.

Do not record mock outputs as if they were successful runs. If a step is not available, state that honestly in the recording.
